# Translation Coverage

Count every human-readable string leaf (names/descriptions/stories/facets) once per English/multilingual index or detail resource and version. Repeated text in index/detail or levels is counted again. Icons, code names, tags, formats, numeric-only strings, calculation directives, icon-only controls and non-English locale branches are excluded. Thai coverage means a validated TH TextMap value, including intentional English/proper names; thaiScriptOccurrences counts actual Thai script separately. Empty/placeholder/source-key fields count as missing. All other untranslated eligible strings count as English fallback.
